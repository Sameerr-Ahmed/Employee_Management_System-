## 🗂️ Employee Data Model

Each employee record includes:

- Full Name  
- Father’s Name  
- CNIC  
- Address  
- Year Joined  
- Pay Grade (1–15)  
- Employee ID  
- Basic Salary  

Data is managed efficiently using arrays with a fixed upper bound for controlled memory usage.

---

## 💰 Salary Computation Logic

The system calculates total take-home salary using standard allowance rules:

| Allowance Type | Percentage |
|----------------|------------|
| House Rent     | 45%        |
| Medical        | 5%         |
| Conveyance    | 10%        |

**Formula:**
```

Take-Home Salary =
Basic Salary + House Rent + Medical + Conveyance

```

This demonstrates **mathematical logic implementation and financial computation accuracy**.
